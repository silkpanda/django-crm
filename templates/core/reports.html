Stage conversion

{% for row in conversion %} {% endfor %}
StageReachedAdvancedRate
{{ row.label }} {{ row.reached }} {{ row.advanced }} {% if row.rate is not None %}{% widthratio row.rate 1 100 as pct %}{{ pct }}%{% else %}—{% endif %}

Of the deals that ever stood in this stage, how many reached a later one. Read from the change history, not from where deals sit today: a rate built from current stages counts only the deals you still have, which rises as the pipeline empties. The final stage has no stage after it, so nothing advances from it and its rate is 0% — a measurement, not a gap in the data. A dash means nobody reached that stage at all.

Open and closed are counted separately on purpose. "Open" is live pipeline and "closed" is what has been decided, and folding them together produces a win rate that moves every time a deal is created rather than every time one is won. A dash means nothing has closed yet, which is a different statement from a zero.
