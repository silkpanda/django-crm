The buckets above are filtered to status=OPEN, so ticking the wrong box used to delete the task from the only screen that showed it — and the reopen toggle lived inside that OPEN-only loop, so it could never render. Two sections close that: what you finished recently (where the toggle finally has something to sit on) and, for an Admin, what everyone else has outstanding. Both reuse the same POST form as the buckets above, so completing, reopening and the no-JavaScript fallback all behave identically. The `next` is left off: on My Day there is nowhere better to go. {% endcomment %}
