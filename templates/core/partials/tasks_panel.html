{% comment %} tasks_panel.html: the open tasks hanging off a company, contact or deal. QA-06. Included in the right column of all three detail pages, below Details, so the task you just made from this page is still here when you land back. TEACHING NOTE: `task_rows` is a list of dicts built in the view — see RecordDetailView.get_context_data. The template cannot call can_edit() to ask "may THIS viewer tick THIS box", and it cannot compare a date against now to decide whether a task is late. Both answers arrive pre-computed, one per row. SECURITY NOTE: the complete form and the Edit link render only for rows the view marked `editable`. That is politeness, not the lock — a Viewer who types the URL still gets a 403 from can_edit in the view. Hiding the button stops nobody; the server-side check stops everybody. The hidden `next` carries the page this panel is on, so ticking a box returns you here instead of dumping you on My Day. It is user input, so the view re-validates it against this host before using it (see task_next_url). {% endcomment %} {% load humanize %}
