The whole thing is behind `can_switch_scope`, and that is politeness, not security: Reps and Viewers have no choice to make (core/scope.py decides it from their role) and typing ?scope=team into the URL changes nothing for them. Hiding a control stops nobody; scoped_deals() is what actually narrows the numbers. `aria-current="true"` on the active link is the same fact announced to a screen reader instead of only shown in colour — two buttons that differ by a background colour tell a blind user nothing about which one is selected. {% endcomment %} {% if can_switch_scope %}
