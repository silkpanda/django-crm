{% extends "base.html" %} {% comment %} quote_form.html: the line editor — every line of the quote, on one page. TEACHING NOTE — it is nearly templates/core/form.html and deliberately not an {% include %} of it. That shared form renders whatever single-record fields it is handed; this page has TWO kinds of thing, and they do not go in the same place. valid_until and notes are the quote's own and sit at the top like any other record. The lines are a formset: an unknown-at-write-time number of rows, each of which is its own little form with its own fields, its own validation and its own DELETE checkbox. `{{ form }}` cannot render that, and an attempt to loop a formset through it produces one form per line — which the browser then submits as several POSTs, so half the quote saves and the other half does not. The layout comes from core/partials/field.html, so a line's inputs look exactly like a company's. `description` is `wide` because it is the field people type into; quantity and unit price sit side by side underneath, which `.form-grid` gives for free at two columns. {{ formset.management_form }} is not optional. It carries the TOTAL_FORMS count and each row's index, and Django's formset reads them to know how many rows came back. Leave it out and every submission is an empty formset with a validation error about it, which is a genuinely baffling first hour. The DELETE checkbox appears ONLY on rows that exist. It is not hidden by CSS or disabled — on a blank row there is nothing to delete, and a checkbox that offers to remove a line the database has never heard of is a small lie about what the form does.
