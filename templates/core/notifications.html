{% extends "base.html" %} {% comment %} notifications.html: everything this user has been told, newest first. TEACHING NOTE — every row is a POST form, not a link. That looks awkward and is the whole design: the bell's number only falls when a notification is marked read, and a plain cannot change anything on the server. So the row posts to notification_read, which stamps read_at and then redirects onward to whatever the notification was about. One control does both jobs, and it works with JavaScript switched off. There is no separate "mark read" tick next to the text for the same reason: two controls for one action is two chances to ship a button that only half works, and one of them always gets forgotten. SECURITY NOTE — `url` comes out of a database column, so it is escaped by default here and there is no |safe anywhere on this page. Nothing a browser sends ends up in that column (core/notifications.py writes it from reverse()), but "nothing does today" is not a property a template should depend on. {% endcomment %} {% load humanize %} {% block title %}Notifications{% endblock %} {% block content %}
