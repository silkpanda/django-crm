TEACHING NOTE: `csrf_token` puts a hidden, per-session secret in the form. CSRF (Cross-Site Request Forgery) is another website getting your browser to submit a form here. That site can't read the secret, so its forged POST is rejected. The hidden `next` field is where you were headed before being sent here. LoginView only follows it if it points back at this same site, so a `next` of https://evil.example is ignored. That stops this login page being used as a trusted-looking hop to a phishing site. {% endcomment %} {% block title %}Sign in{% endblock %} {% block auth %}
